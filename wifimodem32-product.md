### Description

Retro is cosmo, again! The ArcaneByte WiFiModem32 is a Hayes-compatible wifi modem for vintage computers with an RS232 serial port that can be used to connect to Internet-based resources.

With the WiFiModem32, you can connect to your favorite Internet-based BBS using an IP address rather than a phone number. Transfer files using zmodem or Kermit @ 1200 baud for that true vintage experience. If you want to host a BBS, enable the TCP/IP listener function to ‘dial in’ to your retro machine. The possibilities really are endless!

The ArcaneByte WiFiModem32 is a hand-built device that utilizes firmware authored by Bo Zimmerman (available on Github) and an ESP32-based chipset. With the Arduino IDE you are free to install any firmware you see fit. The device is powered by a USB-C cable and requires 5V to operate. Connect the WiFiModem32 directly to your DB25 serial port, or use a straight-through extension cable and/or DB9 adapter and/or gender changer, if necessary. Supports common baud rates (300, 1200, 2400, 4800, 9600, 19200+).

The ESP32 chipset offers more functionality over the ESP8266 chipset used in previous variants, and can support SSH and other functionality baked into Zimodem.
